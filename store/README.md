# Visuels stores (hors site)

Le site public lit uniquement `assets/` et `badges/`. Ici : fichiers à uploader dans les consoles.

| Dossier | Store | Voir |
|---------|-------|------|
| `apple/` | App Store | `apple/NOTES.md` |
| `google/` | Play Store | `google/NOTES.md` |

Dans chaque store : `conforme/` (tailles OK) et `non-conforme/` (à ne pas uploader).
